1 · The approach, in plain termswhat we're building and why it's a good fit

What changes

  • Both sites move to Edge Delivery Services — Storyboard (editorial) and Media Room (pressroom), one platform.
  • Authored in Document Authoring — editors work in a familiar document-style tool; no heavy CMS to run.
  • Pages are static and fast — served from Adobe's CDN, built for strong Core Web Vitals.
  • Media comes from AEM Assets — one approved source of images; the site generates the right sizes automatically.
  • Listings & search from a content index — homepage rails, filters and listings populate themselves from your tags.

Why it helps

  • No plugin sprawl — the current site carries a large custom WordPress + jQuery stack; the rebuild is clean and maintainable.
  • Fast by default — static delivery, images optimised at request time, no server rendering to wait on.
  • Author once, reuse everywhere — the same building blocks serve every page type on both sites.
  • A repeatable method — the pipeline and patterns here become the blueprint for future VW Edge Delivery sites.
We're not starting from a blank page. A working English version already runs live, so this is about closing the remaining gaps and assembling the parts, not building from zero.

2 · What's already runninglive today on the English site

  • The full site frame — header, mega-menu, footer, language switcher, section switcher.
  • The Storyboard homepage — hero, featured promo, Latest Stories with load-more, and topic rails (eMobility, Lifestyle, Škoda World, Latest News) that populate themselves from tags.
  • Story pages — a set of real articles imported and published.
  • The engines underneath — the content index that drives the rails and listings, tag-based inclusion/exclusion, image optimisation, and the import pipeline that brings content across.
The three functions flagged as tricky are already working. Excluding items from listings, placing a story in more than one category, and mixing manual picks with tag-based recommendations, all live on the English site today.
