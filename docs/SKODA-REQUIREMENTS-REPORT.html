6 · Demo / Go-Live SplitM1 = 15 Oct 2026 (functioning demo · VW blueprint) · M2 = 02 Jan 2027 (go-live)

M1 — Functioning Demo · 15 Oct 2026 (~5.5 wks)

A credible, end-to-end EDS demo + the repeatable VW blueprint. Mostly gap-closing & assembly of already-built parts.

  • Tier 1Storyboard /en homepage — built; polish only
  • Tier 1Story detail pages — built (48 imported); extend a few
  • Tier 1Media Room homepage — new assembly from built blocks
  • Tier 1One Model page — new assembly
  • Tier 1"Not-OOTB" trio (exclude / multi-category / manual+tag) — built, narrate
  • Tier 2Media cart — full UI + loop-closing download of a curated set (reduction/ZIP deferred)
  • Tier 2AEM Assets curated set in use (fallback: pipeline/CDN)
  • Tier 2EN + CS on homepage + one story + language selector
  • Tier 2One faceted listing (demo facet subset, index-only search)
  • Tier 21–2 Figma-to-AEM components, generated agentically
  • Tier 3"Repeatable VW blueprint" narrative (5 min)

M2 — Go-Live · 02 Jan 2027 (~16 wks)

Full content migrated, authoring workflows running, WordPress decommissioned.

  • Full content migration at scale (all templates, bulk import + publish/reindex)
  • Press Kit template — narrative, grouped media + ZIP, FAQ, variants (805–808)
  • Category / Series page templates assembled
  • Press Release detail at scale + audio/PDF/infographic
  • Media cart production hardening — server-side reduction, whole-kit ZIP, signed access, cross-device (902, D2)
  • Remaining locales DE/SK/SR/SL on-demand + EW Translation (D1)
  • Content embargo / restricted pre-publication — staged publish (D9)
  • Restricted end-user access (QR) — model to define (D17)
  • Roles & permissions, audit, governance/RACI (D15/D16)
  • Analytics full wiring (GA+FB+Yoast; bespoke layer TBD — D10)
  • Banners (D3), Newsletter (D4), hosted search (D6) — rebuild-as-service or defer
  • URL redirect map execution + full SEO
The real risk is client-side, not build-side. The Tier-1 M1 items are unblocked assembly. The Tier-2 items each depend on a client decision (D5 AEM Assets instance · D2 cart download · D1 CS content · D11 Figma · D12 facet subset) — and each has a fallback that keeps the demo whole if a dependency slips. Start those clocks in Week 1.
